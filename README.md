# Site Dois Blazor

Projeto desenvolvido para a atividade prática de Desenvolvimento Web utilizando **C#**, **.NET 10** e **Blazor**.

A atividade trabalha conceitos básicos de interatividade e navegação entre páginas.

## Exercícios desenvolvidos

### 1. Conversor de Temperatura
Página que recebe uma temperatura em Celsius e converte o valor para Fahrenheit.

### 2. Calculadora de Média
Página que recebe duas notas, calcula a média aritmética e informa se o aluno foi aprovado ou reprovado.

### 3. Sorteador de Números
Página que gera um número aleatório entre 1 e 100.

### 4. Menu de Navegação
Os três exercícios foram adicionados ao menu lateral utilizando `NavLink`, permitindo acessar as páginas sem digitar as rotas manualmente.

## Tecnologias utilizadas

- C#
- .NET 10
- Blazor
- HTML
- CSS

## Como executar

Entre na pasta do projeto:

```bash
cd SiteDoisBlazor
```

Execute:

```bash
dotnet restore
dotnet watch
```

Depois, acesse o endereço exibido no terminal.
